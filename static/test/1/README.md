# ZENITH 天顶 — 3D 超级英雄城市破坏模拟器

一个可以直接在浏览器里运行的 3D 超能力飞行 + 城市破坏游戏。原创角色"天顶"：石墨黑战衣、金色饰边、象牙白披风、发光的琥珀色双眼。

## 运行方式

**方式一：直接打开**
双击 `index.html` 即可（所有脚本都是普通 `<script>`，不依赖 ES Module，因此 `file://` 下也能运行）。

**方式二：本地服务器（推荐）**
```bash
python -m http.server 8000
```
然后访问 <http://localhost:8000>。

> 需要联网：Three.js r159 从 CDN 加载（cdnjs 为主，jsDelivr 备用）。浏览器需支持 WebGL 2（新版 Chrome / Edge / Firefox / Safari 均可）。

## 玩法要点

- **撞穿建筑**：飞行速度超过约 65 km/h 撞墙即可撞穿，破洞可以看到建筑内部和另一侧；速度越快破洞越大、减速越少。
- **大楼坍塌**：建筑累计损伤达到阈值后整体下沉坍塌，伴随巨量烟尘与碎石堆。低层被撞、极速撞击、射线切割底部会造成更多损伤。
- **小型建筑**：独栋住宅、报亭、小商铺被高速撞击时会被直接摧毁。
- **街道道具**：汽车会被撞飞并可能爆炸（还会连锁引爆附近车辆）；路灯、树木、红绿灯低速时被撞倒，高速时被撞飞；消防栓被撞会喷水。
- **俯冲砸地**：从高空高速俯冲撞向地面 → 巨大冲击波、弹坑、扬尘，周围车辆与道具被掀飞、玻璃震碎。
- **音爆**：极速突破 1 马赫时产生蒸汽环、球形激波、闪白、镜头震动与低频爆响，并震碎附近玻璃。
- **贴地 / 贴楼高速飞行**：扬起尘土、车辆晃动、树木被气流吹弯、沿途玻璃被震碎，并有风压呼啸声。

```

js/hero.js              角色模型、姿势混合、Verlet 披风
js/controller.js        飞行物理、状态机、碰撞与落地

```

## 性能设计

- 约 6500 栋方盒建筑共用 **一个 InstancedMesh**（一次绘制调用），窗户与幕墙全部在着色器中程序化生成。
- 破坏不使用真实刚体：每栋建筑在一张浮点纹理中有 16 个"破坏胶囊"槽位，片元着色器据此挖洞、碎窗；受损时才追加内部背面实例。
- 街道道具按 960 m 分区实例化并按距离裁剪；碎块、粒子、冲击波全部使用对象池，远处碎片自动加速消失。
- 简化碰撞体（轴对齐包围盒 / 圆柱 / 定向盒）+ 空间哈希网格；高速移动按子步检测，防止穿透。
- 帧率不足时自动降低渲染分辨率（最低 60%），启动时预热全部着色器以避免首次撞击卡顿。
