模型说明与参考资料

采用二维几何光学模型：点光源均匀向各方向发射光线，墙面完全镜面反射，无吸收、散射或衍射。椭圆、圆弧及直线均使用解析求交与法线反射。两条外椭圆的长半轴 a = 400、短半轴 b = 280，焦距 c = √(a² − b²)，伞形端点位于 (±c, ±100)。恰好击中尖角的光线没有唯一反射法线，演示会终止该光束。

演示使用有限光束及反射次数；到达上限后可重新发射或调整参数。几何暗区为理论确定的不可达区域，不是根据画面亮度估计。光路线宽和光点光晕仅用于可视化。屏幕坐标 X 向右、Y 向上，以长半轴 a 归一化。此结论适用于理想射线模型；波动衍射不在本演示范围内。

几何构型与原理参考：COMSOL · Penrose unilluminable room；Ray Optics Simulation · 交互模型。
